# 개인정보 처리방침

> **서비스명**: 오늘도 출근합니다 (today-office)
> **시행일**: 2026-05-07
> **최종 수정일**: 2026-05-07

본 처리방침은 「개인정보 보호법」 제30조에 따라 정보주체의 개인정보를 보호하고 이와 관련한
고충을 신속하고 원활하게 처리할 수 있도록 하기 위하여 수립·공개합니다.

> ⚠️ **법적 검토 필요** — 본 문서는 MVP 출시용 템플릿이며, 실제 운영 전 법무 검토를 권장합니다.

---

## 1. 처리하는 개인정보의 항목

본 서비스는 익명 채팅 서비스의 특성상 **이름·이메일·휴대전화번호·주소 등 직접 식별
가능한 개인정보를 일체 수집하지 않습니다.** 다음의 정보만 처리합니다.

| 항목 | 수집 시점 | 비고 |
|------|----------|------|
| 익명 식별자 (Anonymous Key) | 앱 최초 실행 시 | 토스에서 발급한 익명 키 또는 자동 생성된 UUID. 실명·연락처와 매칭되지 않음. |
| 닉네임 | 자동 생성 (사용자 수정 가능) | 예: "오늘의출근러", "조용한승객" 등 무작위 풀에서 선택 |
| 아바타 설정 | 사용자 입력 시 | 피부톤·헤어·표정·복장 색상 코드 |
| 메시지 내용 | 사용자 전송 시 | 40자 이내, **전송 후 10초 자동 삭제** |
| 좋아요 기록 | 좋아요 클릭 시 | 메시지 ID + 익명 식별자 |
| 신고 기록 | 신고 시 | 메시지 ID + 신고자 익명 식별자 + 사유 |

본 서비스는 **자동 수집되는 단말기 정보(쿠키·IP·기기 식별자)도 별도로 저장하지 않습니다.**
다만 토스 앱 자체가 수집할 수 있는 정보는 토스 개인정보 처리방침을 따릅니다.

---

## 2. 처리 목적

수집된 정보는 다음의 목적 외에는 사용되지 않습니다.

1. 익명 채팅 서비스 제공 (메시지 송수신, 좋아요, 신고)
2. 욕설·개인정보 유출 등 부적절한 콘텐츠 차단
3. 부정 사용 방지 (속도 제한, 어뷰징 차단)

| 항목 | 보유 기간 |
|------|----------|

| 익명 식별자·닉네임·아바타 | 사용자가 앱을 삭제하거나 프로필을 초기화할 때까지 |

## 6. 정보주체의 권리·의무 및 행사 방법

정보주체는 다음 권리를 행사할 수 있습니다.

1. **개인정보 열람·정정·삭제 요구**: 앱 내 프로필 화면에서 닉네임·아바타를 직접 수정·초기화할 수 있습니다.
2. **처리 정지 요구**: 앱 삭제 시 익명 식별자도 함께 삭제됩니다.
3. **신고 철회**: 본 처리방침 하단의 고객센터로 연락 시 처리합니다.

## 7. 개인정보 안전성 확보 조치

- 모든 통신은 HTTPS/TLS 로 암호화됩니다.
- 데이터베이스는 Row-Level Security 정책으로 접근이 제한됩니다.
- 메시지는 서버 트리거를 통해 다음 항목을 자동 검증하며, 위반 시 저장되지 않습니다.
  - 길이 제한 (40자 이내)
  - 개인정보 (전화번호·이메일·주민번호·SNS 유도·카카오 오픈채팅)
  - 외부 URL/링크
  - 금융 사기 키워드 (투자 권유·코인 리딩 등)
  - 운영자/토스 사칭
  - 광고·외부 유도 키워드
  - 욕설·차별·혐오·음란 표현 (한국어·영어, 변형 우회 패턴 포함)
  - 도배 스팸 (동일 글자 반복)
- 동일 사용자가 6초 내 반복 전송 시 차단됩니다.
- 서버 cron 작업이 1분 주기로 만료된 메시지 및 그에 딸린 좋아요·신고 데이터를 영구 삭제합니다.
