## 폴더 구조
- backgrounds/ : 메인 지하철 배경
- avatars/ : 기본 아바타 2종, 흰 티 캐주얼 버전
- items/ : 아바타에 착용/배치할 수 있는 꾸미기 아이템
- lines/ : 1~9호선 낱장 지하철 아이콘
- sample-sheets/ : 스타일 샘플 및 노선 아이콘 전체 시트
- raw-generated/ : 이전 버전 백업용 생성 이미지
